# Optional AI assistance

The desktop can link the shipped customization and read-only diagnosis skills
into a user's agent configuration. The links target only the two managed skill
trees and preserve custom agent paths. Agent installation uses an existing
mise installation and never adds system package repositories.

Crash diagnosis starts only after an explicit user action. Hang detection is
opt-in. Prompts exclude untrusted window titles and never ask an agent to kill
an application-supplied process ID. The Settings frontend remains unprivileged.
